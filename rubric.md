# Scoring Rubric

Score each output 1-5 on four criteria. Apply the anchors exactly as written
and do not change them once scoring has started.

## Relevance
_Does the output address what the input actually asked for?_

| Score | Anchor description |
|---|---|
| 1 | Irrelevant; ignores the request or the supplied context. |
| 2 | Addresses the right general topic but answers the wrong question. |
| 3 | Answers the question, but a noticeable part of the response is unnecessary material. |
| 4 | Answers the request directly and respects the constraints; one short piece of unnecessary preamble. |
| 5 | Serves the request exactly; all constraints followed (e.g. length); no filler or off-task content. |

## Accuracy
_Is the output factually correct relative to the input or to verifiable fact?_

| Score | Anchor description |
|---|---|
| 1 | Mostly wrong; multiple errors or fabricated facts that change the meaning. |
| 2 | One major error (a core fact wrong or meaning reversed) or three or more minor errors. |
| 3 | No major error, but two minor errors (a wrong detail or an overstated claim). |
| 4 | One minor inaccuracy or imprecise wording; all central facts correct and traceable to the source. |
| 5 | Every claim is correct and supported by the input or verifiable fact; nothing inverted or distorted. |

## Tone
_Is the tone and style appropriate for the task?_

| Score | Anchor description |
|---|---|
| 1 | Wrong register throughout; hostile, flippant, preachy or incoherent for the task. |
| 2 | Frequently off; heavy filler, excessive hedging or moralizing. |
| 3 | Acceptable but generic; some filler words, nothing distracting. |
| 4 | Appropriate and clear; one small lapse (an unneeded hedge or filler phrase). |
| 5 | Register fits the task exactly; concise, natural, confident without overclaiming. |

## Completeness
_Does the output cover everything it should, without missing key parts?_

| Score | Anchor description |
|---|---|
| 1 | Covers almost none of the key points; empty or cut off mid-answer. |
| 2 | Covers fewer than half of the key points; a major part of the request is not covered. |
| 3 | Covers about half to three quarters of the key points; the gist is there but notable gaps remain. |
| 4 | Covers all but one minor point; nothing essential missing. |
| 5 | Covers every key point and every part of the request, with no truncation. |
